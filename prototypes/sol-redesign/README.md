# Sol redesign: primary design evidence

2026-11-16: пользователь выбрал **Sol**, палитру **графит + индиго**, ошибки через постоянный **alert** с повтором запроса. Источник: «Давай графит + индиго, ошибки оставим через alert. Приступай к реализации варианта sol».

- `layouts.html`: автономные макеты независимых направлений Terra и Sol.
- `palette.html`: автономный подбор нейтралей и акцентов на компоновке Sol.
- `terra.md`, `sol.md`: независимые исследования, источники, палитры и контраст.
- `comparison.md`: сводка и компромиссы.

HTML открывается напрямую в браузере. Данные вымышлены. Файлы — одноразовые прототипы, а не production-код; пользовательский выбор реализуется заново в `main`.

Согласованный экран: поля артикула и производителя сверху, результаты во всю ширину; на телефоне поля идут последовательно, предложения показаны с подписями. Светлая/тёмная/системная темы. Без декоративного логотипа, бейджа «Демо-доступ», повторных заголовков и инициала бренда.
